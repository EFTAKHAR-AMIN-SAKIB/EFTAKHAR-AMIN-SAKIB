### Things I've Built

**[TTC Network](https://ttcnetwork.xyz)** · [Source](https://github.com/EFTAKHAR-AMIN-SAKIB/ttc-network)
A centralized academic and community platform built to connect students, teachers, and alumni across all Government Teachers' Training Colleges (TTCs) in Bangladesh. Built with Next.js 14, TypeScript, Firebase, and a companion Kotlin Android app, it addresses fragmented institutional communication by bringing real-time campus feeds, interactive student polls, and verified notice boards with deadline alerts into one place. Behind the scenes, it uses a 4-tier role-based access system (Admin, Manager, Teacher, Student) with strict multi-tenant data isolation, offline caching, and deep linking for smooth web-to-mobile synchronization.

**[MyLaws](https://mylaws-bd.vercel.app)** · [Source](https://github.com/EFTAKHAR-AMIN-SAKIB/mylaws-website)
A citizen-first legal information and document preparation assistant for Bangladesh that makes statutory law understandable, accessible, and actionable. Built with Next.js 15, TypeScript, Tailwind CSS, and Cloudflare D1. Rather than generating ungrounded AI summaries, it anchors its guidance in 255 verified provisions across 31 Acts from official gazetted law (bdlaws.minlaw.gov.bd), verified by a strict citation validator and a deterministic legal state machine fallback. It guides citizens through a 4-step workflow: source-linked explanations, clarifying diagnostic questions, statutory deadline checklists, and automatic complaint drafting. It also features a custom client-side Bengali PDF synthesis engine that handles complex script shaping and vowel placement directly on canvas, producing formal petitions ready for submission to government offices like DIFE, DNCRP, or local police stations.

**[TenderPack](https://tender-pack.vercel.app)** · [Source](https://github.com/EFTAKHAR-AMIN-SAKIB/tender-document-package-builder)
A client-side tender document package builder and verification engine built for the AI DevFest hackathon, where it won 18th place in the Vibe Coding track. Built with React, TypeScript, Tailwind CSS, and pdf-lib, it eliminates bid disqualifications caused by clerical errors, expired trade licenses, missing solvency certificates, or misplaced files in procurement bids. Designed with a zero-server upload privacy architecture: all PDF parsing, Web Crypto SHA-256 duplicate detection, expiry checks against submission deadlines, and document stitching happen entirely in-memory within the browser. It features a bilingual interface (English and Bengali) and compiles clean, indexed tender dossiers with automated cover and contents pages.

**[Treat](https://treat-app-site.vercel.app)** · [Source](https://github.com/EFTAKHAR-AMIN-SAKIB/treat-landing-page)
A social dining and restaurant-deal platform built for squad feasts, dynamic group discounts, 2-minute table holds, and live kitchen synchronization. As a team contributor, I built the product showcase website featuring an interactive Three.js 3D mobile phone viewport, dynamic squad budget calculators, and an admin studio for real-time content management. I also contribute to the cross-platform Flutter mobile application, developing responsive UI screens, reusable components, and client-side state management.

**[Unified Privacy Guard](https://github.com/EFTAKHAR-AMIN-SAKIB/Unified-Privacy-Guard)**
A browser extension that gives you real-time visual privacy across Facebook, WhatsApp Web, and Telegram Web. Features selective blur, blackout redaction, and hover-to-reveal for sensitive messages, contacts, and media. Everything runs 100% locally with zero data collection, built for anyone who shares their screen, works in public, or just wants their chats to stay their own. Available on the [Chrome Web Store](https://chromewebstore.google.com/detail/olcpngjbicmheefpoagglhoohfbgiodl) and [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/unified-privacy-guard/kodkhfbjakjdobnfkjjbljnofofdlgdg).
